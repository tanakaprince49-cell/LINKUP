# LINKUP 16.10.0 — LvlUp Ventures Deal-Flow Demo (2026-10-27)

Public, login-free investor demo at **`/app/lvlup`**: Type an investment thesis,
Linky searches every public builder profile and returns ranked founders with
receipts. Real data only — zero demo theatrics.

## What shipped
- **Public API mode (`api/publicSeo.js?mode=lvlup`)**: bounded 60-doc scan of
  `publicProfiles` hydrated through the existing `currentProfiles` allowlist —
  stealth/invisible builders excluded, no private fields ever (same projection
  as `/builders`). Deterministic scoring + template briefs (no AI jitter, demo
  can't hallucinate). CDN-cached JSON (`s-maxage=300`) so VC visits sip quota.
  `digest=1` variant returns the weekly-digest payload (week label + thesis +
  picks). No new serverless function (still 11/12 Hobby slots, one-function-
  per-domain ethos kept).
- **`LvlupDemoScreen` (Expo, linking path `lvlup`)**: ink hero with live stats,
  thesis search + 6 thesis chips, ranked match cards (avatar, score pill + bar,
  matched-term chips, Linky brief, skills, public-profile deep link),
  weekly-digest preview, 3-step onboarding, thesis-call CTA
  (`mailto:tanakaprince49@gmail.com`, prefilled subject + body) and Play Store
  link. Mounted in BOTH signed-out (unconditional — investor has no account)
  and signed-in stacks. No Firebase imports = zero quota from page views.
- **Web metadata**: `LvlUp Ventures deal flow demo | LINKUP` tab title, auto-
  `noindex` (private VC demo stays out of search engines).
- **Tests**: `tests/lvlup-demo.test.mjs` (6 tests — ranking order, no-leak,
  stealth exclusion, determinism byte-check, digest shape, limit clamp + cache
  headers), registered in `test:seo` (now 49 tests).
